# public-emini-day-trader

Investor style day trading system for planned growth in the ES.

## Expo app scaffold

This repository now includes a full Expo Router app scaffold so visitors can see how the app is structured and built.

```text
expo-app/
├── app/
│   ├── (tabs)/
│   │   ├── _layout.tsx
│   │   ├── index.tsx
│   │   └── two.tsx
│   ├── +html.tsx
│   ├── +not-found.tsx
│   ├── _layout.tsx
│   └── modal.tsx
├── assets/
│   ├── fonts/
│   │   └── SpaceMono-Regular.ttf
│   └── images/
│       ├── adaptive-icon.png
│       ├── favicon.png
│       ├── icon.png
│       └── splash-icon.png
├── components/
│   ├── __tests__/
│   │   └── StyledText-test.js
│   ├── EditScreenInfo.tsx
│   ├── ExternalLink.tsx
│   ├── StyledText.tsx
│   ├── Themed.tsx
│   ├── useClientOnlyValue.ts
│   ├── useClientOnlyValue.web.ts
│   ├── useColorScheme.ts
│   └── useColorScheme.web.ts
├── constants/
│   └── Colors.ts
├── .gitignore
├── app.json
├── package.json
└── tsconfig.json
```

Scaffolded with `create-expo-app` (tabs template). To run locally:

```bash
cd expo-app
npm install
npm run start
```
